# Requirements traceability

The ten official SIH26263 requirements, mapped to what exists in this repository.

Status values:
- **implemented**: works in the prototype and is tested.
- **simulated**: works against a simulated dependency.
- **planned**: designed, not built.

Test files are in `backend/tests/`. "Demo A/B/C" means `scripts/run_demos.py`.
